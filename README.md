# 🎵 Spotify Web

A full-stack starter project for building a Spotify-inspired web application with a **React + Vite frontend** and an **Express backend**.

---

## 📁 Project Structure

```text
Spotify_web/
├── frontend/   # React + Vite client
└── backend/    # Express server
```

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, ESLint
- **Backend:** Node.js, Express

---

## 🚀 Getting Started

### 1) Clone the repository

```bash
git clone https://github.com/subeerkr/Spotify_web.git
cd Spotify_web
```

### 2) Install dependencies

```bash
cd frontend && npm install
cd ../backend && npm install
```

---

## ▶️ Run the App

### Start frontend (development)

```bash
cd frontend
npm run dev
```

### Start backend

> Add your backend start script (for example, `npm run start`) once your server entry file is ready.

---

## ✅ Available Commands

### Frontend

```bash
npm run dev     # Run Vite dev server
npm run build   # Create production build
npm run lint    # Run ESLint
npm run preview # Preview production build
```

### Backend

